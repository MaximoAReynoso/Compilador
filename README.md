# Compilador
---

## Como compilar el proyecto para obtener el ejecutable
```./execute.sh```

## Como probar el compilador
Una vez se haya compilado y obtenido el ejecutable se puede ejecutar lo siguiente:

```./compilador tests/errores/detectados/Nro_error_detectado```
<br><br>o tambien puede ser<br><br>
```./compilador ruta_archivo_a_probar```
